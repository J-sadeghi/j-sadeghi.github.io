# Jafar Sadeghi – academic homepage

Jekyll site (built automatically and free by GitHub Pages) in the style of the Hugo "Academic" theme.

## Edit the site
Go to https://app.pagescms.org, sign in with GitHub, open this repository and use the forms:
- Home page: biography, photo, CV, interests, education, contact
- Journal articles / Preprints / Conference presentations / Invited seminars: add, edit, reorder entries
- Research group: members by level, former members
- Pages: Teaching, Refereeing, Memberships, Responsibilities (rich text, images) – or add a new page
- Menu: the top navigation bar

Changes go live 1–2 minutes after saving.

## Where things are
- `index.md` – home page
- `pages/*.md` – other pages (address: /post/<file name>/)
- `_data/*.yml` – publication lists, research group, menu
- `img/` – images (photo, figures); `pdf/` – CV
- `_layouts/`, `_includes/`, `assets/` – design (normally no need to touch)
